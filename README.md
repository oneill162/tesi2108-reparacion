# TESI 2108 – Reparación de Computadoras

Presentaciones interactivas del curso TESI 2108, Instituto Tecnológico de Puerto Rico, Recinto de Manatí.
Prof. Eduardo O. De Jesús Arroyo · Primer semestre 2026-2027.

Página del curso: https://oneill162.github.io/tesi2108-reparacion/

## Contenido

| Archivo o carpeta | Qué es |
|---|---|
| `index.html` | Portada del curso con las unidades |
| `unidadA.html` | Unidad A: Introducción (tema: museo de la computación) |
| `assets/deck.css`, `assets/deck.js` | Motor común de las presentaciones (heredado de TESI 2105): escala, transiciones, barra, índice, temporizador |
| `assets/fonts/` | Schibsted Grotesk y JetBrains Mono (licencia SIL OFL) |

## Uso en clase

Flechas o barra espaciadora para avanzar, **I** abre el índice, **F** pone pantalla completa. `#12` al final del enlace abre la lámina 12.

Las fotos se cargan desde Wikimedia Commons, así que la proyección necesita Internet. Si una foto no carga, la lámina muestra su descripción en su lugar. Los créditos y licencias están en la penúltima lámina de cada unidad.

Para OrbundSIS:

```html
<iframe src="https://oneill162.github.io/tesi2108-reparacion/unidadA.html" style="width:100%; aspect-ratio:16/9; border:0;" allow="fullscreen" allowfullscreen title="TESI 2108 – Unidad A: Introducción"></iframe>
```

Las claves y hojas de respuestas de evaluaciones **no** se publican en este repositorio. Los ejercicios cortos de cada unidad son de práctica, con corrección inmediata.
